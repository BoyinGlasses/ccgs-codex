---
name: ccgs-new-game
description: Create a new Codex Game Studios game project from the complete ported template when the user asks to start a CCGS project.
---

Copy the template at `../../assets/template` into the user-chosen new project directory.
Do not overwrite existing files. Open that project in a new Codex task, then run
`$ccgs-start`. The project includes `AGENTS.md`, native Codex agents, skills,
hooks, templates, code, and production structure. On first open, Codex may
require review and trust of the project hooks through `/hooks`.
